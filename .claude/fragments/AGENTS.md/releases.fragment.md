**Releases.** Tagging `v*` triggers the GoReleaser release workflow in `.github/`, which builds the release binaries (darwin arm64/amd64, linux amd64), publishes a GitHub release, and updates the Homebrew tap. `release-tag.yml` pushes that tag itself on each merge to `main` that changes the binary's sources, so a merged fix needs no hand tag. The version comes from the tag, and the release runs only against a merged commit on `main` — tag `origin/main`, not a feature branch.
